# Research

Read local files, notes, and the web. Do not change records in this pass.

## Steps

1. Restate the question in one sentence.
2. Open 3 or more sources when the question is not local. Cite a URL or path for each finding.
3. Separate findings, hypotheses, and unknowns.
4. Say what would change the answer. Do not guess past the sources.

## Result

- Sources
- Findings, each with a source
- Unknowns
