# Personal loop

Use `/task`. Answer the four routing questions before doing the work.

## Fast

All four answers are no. Do the work. Read back once what changed. Note the result.

## Slow

Any answer is yes. Write a short plan in the task note: goal, context, and the items you will change. Do the work. Read back each changed item. Note the result.

## Read-back

Open the file, page, or record again after the change. The read-back is a fresh look, not a memory of what you wrote. If it does not match the goal, fix it and read it back again.

## Retro

Before you finish a long task, run `/retro` and prepend one lesson.
