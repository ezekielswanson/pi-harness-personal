# Learn

1. Scope the topic in one paragraph: what you want to be able to do, and what is out of scope.
2. Read 3 to 5 sources. Prefer the primary doc, then one or two independent explanations.
3. Write `notes/<topic>.md` with the claim, the source, and a short example.
4. Self-check with 5 questions you can answer from the note without looking. Write the answers under the note. Mark any miss.
5. Optional: add a Notion page for the topic if it should outlive the workspace.

Do not paste token values into the note.
