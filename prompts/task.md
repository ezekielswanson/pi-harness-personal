description: Start a personal task. Four routing questions, then fast or slow work and a read-back.
---
Task: $1

Answer these four questions first:

1. Does this change something outside the workspace?
2. Is this a new kind of task?
3. Are there many items?
4. Are you unsure of the source?

All no: do it, then read back once.
Any yes: write a short plan in the task note, do it, read back each changed item, and note the result.

Use `templates/task.md` for the note. There is no approval step.
